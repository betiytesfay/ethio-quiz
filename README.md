# Ethio Quiz

An interactive mobile quiz app built with React Native and Expo that tests your knowledge about Ethiopia.

## About

Ethio Quiz challenges users with 10 questions covering Ethiopian history, culture, geography, language, and famous personalities. Each question has a 15-second timer to keep things exciting, and instant feedback is given after every answer with a detailed explanation.

## Features

- Welcome home screen with Start Quiz button
- 10 questions about Ethiopia
- 15-second countdown timer per question
- Instant feedback with correct/wrong answer highlighting
- Explanation shown after each answer
- Green progress bar to track quiz progress
- Final score screen with performance message
- End button to restart the quiz at any time

## How to Run

1. Clone the repository
   git clone https://github.com/your-username/your-repo-name.git

2. Install dependencies
   cd QuizApp
   npm install

3. Start the app
   npx expo start

4. Scan the QR code with the Expo Go app on your phone
